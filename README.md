# Taller · Kit de supervivencia para juniors

Proyecto de prácticas del taller de [Código Sin Siesta](https://codigosinsiesta.github.io). Imagina que es tu primera semana
en este equipo: no conoces el código y ya tienes dos tickets asignados.

> Este es un proyecto de juguete. No pongas aquí código de tu empresa, secretos ni datos personales.

## Abrirlo

Es el mismo entorno por dos caminos. Elige uno:

- **En el navegador, sin instalar nada:** pulsa **Code → Codespaces → Create codespace**.
- **En tu ordenador:** instala [Docker Desktop](https://www.docker.com/products/docker-desktop/) y
  [VS Code](https://code.visualstudio.com/) con la extensión **Dev Containers**. Clona este repo y elige **Reopen in
  Container**.

## El proyecto

Comanda gestiona los pedidos y la caja de una cafetería, en JavaScript y sin dependencias.

```bash
npm test     # los tests
npm start    # la API, en http://localhost:3000
```

| Ruta | Para qué |
|---|---|
| `src/` | El código |
| `test/` | Los tests, en verde al empezar |
| `docs/decisiones.md` | Por qué algunas cosas son como son |
| `tickets/` | Tus dos tickets |
| `ejercicios/` | El guion del taller: [empieza aquí](ejercicios/README.md) |
| `scripts/validate.sh` | Comprueba que tu entorno está listo |
