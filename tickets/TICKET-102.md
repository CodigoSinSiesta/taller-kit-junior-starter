# TICKET-102 · El café se abarata solo

**Abierto por:** Luis (camarero) · **Prioridad:** alta

Hoy una clienta ha pagado con un cupón y, desde entonces, el café les sale más barato a todos los que vienen detrás, aunque
no traigan cupón. Si reiniciamos el programa, vuelve a su precio.

## Cómo verlo

```bash
npm run cupon
```

## Qué esperamos

Un cupón solo cambia el precio del pedido que lo usa.
